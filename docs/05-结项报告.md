## 四、部署指南

### 4.1 环境要求
- Windows Server 2019+ 或 Linux；Python 3.11+；4 核/8GB/100GB
- 内网部署；仅钉钉登录需要服务器出站访问 api.dingtalk.com（Mock 模式完全离线可用）

### 4.2 快速启动（演示/试运行）
```
Windows: 双击 scripts\start.bat
Linux:   bash scripts/start.sh
浏览器访问 http://服务器IP:8080
演示账号：Mock 扫码页任选角色；管理员兜底 系统管理员 / admin123
```

### 4.3 目录规划（首次启动自动创建）
```
data/jujie_energy.db   SQLite 主库（WAL）
data/files/            导入导出文件（staging、错误标注、导出物）
data/backup/           每日备份（保留 30 份）
data/secret.key        会话/加密根密钥（务必纳入备份、勿外泄）
logs/app.log           运行日志（按天滚动 90 天）
```

### 4.4 生产部署（Linux systemd 示例）
```ini
[Unit]
Description=Jujie Energy Carbon Platform
After=network.target
[Service]
WorkingDirectory=/opt/jujie
Environment=DINGTALK_MOCK=0
ExecStart=/opt/jujie/.venv/bin/python -m uvicorn server.main:app --host 0.0.0.0 --port 8080
Restart=always
[Install]
WantedBy=multi-user.target
```
备份兜底：`cron` 每日 `curl -X POST -b <admin_cookie> http://127.0.0.1:8080/api/sys/backup`，并定期把 data/ 整体异地拷贝（RPO≤24h）。

### 4.5 钉钉上线步骤
1. 钉钉开放平台创建"扫码登录第三方网站"应用与企业内部应用，取得 CorpId/AppId/AppSecret/AppKey
2. 系统管理 → 钉钉配置：录入并做连通性测试
3. 回调地址：`http://服务器IP:8080/api/auth/dingtalk/callback` 录入钉钉后台
4. 环境变量 `DINGTALK_MOCK=0` 重启服务
5. 管理员在用户管理中为每位员工预建账号（手机号与钉钉一致，首次扫码自动绑定）

### 4.6 运维要点
- 每月做一次恢复演练（系统管理 → 恢复 → 上传最近备份 → 确认）
- 每季度检查 logs/ 与 data/files/ 体积
- 因子年度更新走"排放因子库"界面（变更原因必填，审计留痕），禁止直接改库
